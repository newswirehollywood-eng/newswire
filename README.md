# Newswire Hollywood

Entertainment news, wire distribution, and industry intelligence.

## Structure

- `CLAUDE.md` — standing rules, loads every session
- `runbook/` — how the system operates, agent handoffs, error log
- `agents/` — one file per agent, organized by division
- `data/` — events calendar, contact database, story records
- `style/` — house style guide, sourcing standards
- `.github/workflows/` — scheduled automation
