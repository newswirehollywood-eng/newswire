**1. Posting our content out** — every published story gets a caption drafted for each platform, ready to post. This can start immediately, at zero cost, in a manual form: I draft the post text for every story the moment it publishes, saved to a file Terry's team copies from and posts by hand. No new account, no new tool, no cost — just needs someone on the team willing to paste and hit post.

**2. Fully automated posting, no one touching it** — this is the "if you guys get to post without me being there" version, and it requires three things that don't exist yet: real account access, a scheduling/posting tool with API automation (researched already — Metricool's free and Starter tiers do NOT include API access; only Advanced ($53+/month) does), and that tool's API key stored as a GitHub Secret. **Recommendation**: start with #1 now — costs nothing, and gets content flowing to whoever posts it by hand — while #2 stays a deliberate, priced decision rather than something built by default.
