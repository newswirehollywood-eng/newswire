# WIRE FEED STATUS

Written by wire.py on every run. One block per run: which feeds answered, how
many items each returned, how many of those carried a photo, and the reason any
feed was dropped that hour.

Read this first whenever the site looks thin. A section with no cards usually
means a feed stopped answering, not that the industry went quiet.

A feed that is dropped never breaks the run — wire.py skips it and keeps going
with the rest. A feed that fails every run for days is a real problem: its URL
has probably moved, and it needs replacing in data/feeds.json.
