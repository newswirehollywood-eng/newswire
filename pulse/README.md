# PULSE

This office is Division Four, Industry & Tech Pulse. Its one job: notice what's moving in entertainment, tech, and culture, sort it honestly (shipped today / demoed only / announced only), and write Newswire Hollywood's own short take — not just repost someone else's trending content.

`trend-watch-brief.md` is the running output, written by the Trend Watch agent (`.claude/agents/trend-watch-agent.md`). Append-only by date; corrections happen in place, not by deleting history.

This division does not direct what the Newsroom covers — it flags what's interesting per CLAUDE.md's rule that Revenue and Publicity (and by the same principle, Pulse) don't steer editorial.
